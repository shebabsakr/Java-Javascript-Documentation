A browser-based learning resource for JavaScript, built with HTML and CSS.
It provides structured explanations and code examples to help beginners understand core JavaScript concepts.

📌 Overview
This project organizes essential JavaScript topics into sections that cover everything from basic syntax to more advanced programming constructs.
Users can navigate easily through a fixed sidebar to access topics like variables, conditionals, loops, data structures, functions, and scope.
Code examples are included to illustrate concepts and provide a hands-on reference for learning and experimentation.

🚀 Features
Fixed navigation sidebar with clickable links to each topic
Sections covering core JavaScript concepts including:
Introduction to JavaScript
Variables and data types
Conditionals (if, else if, else)
Loops (while statements)
Functions and first scripts
Unit testing basics
Scope and variable accessibility
Data structures (arrays, objects, maps, sets)
Code blocks with clear formatting and syntax highlighting
Responsive design for mobile and desktop views

🛠 Technologies Used
HTML5 – Structure and semantic layout
CSS3 – Styling, responsive sidebar, typography
Google Fonts – ‘Poppins’ for clean, readable text
Flexbox and CSS Grid – Layout alignment and spacing

⚙️ How It Works
A fixed navigation bar provides quick access to all JavaScript topics.
Each section contains clear explanations with real-world context for learning.
Code blocks show examples of how to declare variables, create functions, use loops, and manipulate data structures.
Responsive design ensures readability on both desktop and mobile screens.
